Introduction: 
SQL Window Functions combined with Aggregate Functions offer a powerful way to perform advanced data analysis by applying aggregate calculations across specific windows of rows within a dataset. This combination allows you to gain insights into trends, rankings, and comparisons within defined windows. By mastering SQL Window Functions with Aggregate Functions, you can efficiently calculate running totals, moving averages, and more, enriching your data analysis capabilities. This document provides a comprehensive understanding of using SQL Window Functions with Aggregate Functions, their syntax, types, use cases, and practical examples, empowering your data manipulation skills on your edtech platform.

 

Introduction to Window Functions with Aggregate Functions:
Combining Window Functions and Aggregate Functions lets you compute aggregates over subsets of data.

This combination enhances analysis accuracy by considering specific window contexts.

 

Common Use Cases: 
a. Running Totals: Calculating cumulative totals within specific windows.

b. Moving Averages: Computing averages for a range of rows around each row.

c. Comparisons: Analyzing performance relative to peers within defined windows.

 

Syntax of Window Functions with Aggregate Functions:
The basic syntax of a window function with an aggregate is:

aggregate_function(column) OVER (PARTITION BY partition_expression ORDER BY order_expression ROWS/RANGE frame_specification)

 

Practical Examples:
Example 1 - Running Total of Sales:

SELECT date, revenue, SUM(revenue) OVER (ORDER BY date) AS running_total FROM sales;

Example 2 - Moving Average of Orders:

SELECT order_date, order_amount, AVG(order_amount) OVER (ORDER BY order_date ROWS BETWEEN 2 PRECEDING AND 2 FOLLOWING) AS moving_avg FROM orders;

Example 3 - Comparative Ranking:

SELECT product_name, unit_price, RANK() OVER (PARTITION BY category_id ORDER BY unit_price) AS price_rank FROM products;

 

Available Aggregate Functions: 
SUM(), AVG(), COUNT(), MIN(), MAX() can be used in combination with Window Functions.

 

Customizing Window Frame:
Define the window frame to specify the range of rows considered in calculations.

 

Best Practices:
a. Understand the specific purpose of each aggregate function.

b. Choose an appropriate window frame to suit your analysis requirements.

c. Test and validate your results with sample data to ensure accuracy.

Question:
Retrieve the first_name, last_name, salary, average departmental salary as "avg_department_salary", and salary difference as "salary_difference" from the average for each employee.

Table: employees
 
ColumnNames		DataType		
employee_id		int		
first_name		varchar
last_name		varchar  
department		varchar 
salary			decimal
manager_id		int


Constraints:
The input table employees contains valid data.


Sample Input:
employees                                     
| employee_id | first_name | last_name | department | salary | manager_id |
|-------------|------------|-----------|------------|--------|------------|
| 1           | John       | Doe       | IT         | 5000.00| 3          |
| 2           | Jane       | Smith     | Finance    | 6000.00| 4          |
| 3           | Mike       | Johnson   | IT         | 7000.00| 5          |
| 4           | Emily      | Davis     | Finance    | 5500.00| 5          |
| 5           | Robert     | Brown     | HR         | 10000.00| NULL      |


Sample Output:
| first_name | last_name | salary | avg_department_salary | salary_difference |
|------------|-----------|--------|-----------------------|-------------------|
| John       | Doe       | 5000.00| 6000.00               | -1000.00          |
| Jane       | Smith     | 6000.00| 5750.00               | 250.00            |
| Mike       | Johnson   | 7000.00| 6000.00               | 1000.00           |
| Emily      | Davis     | 5500.00| 5750.00               | -250.00           |
| Robert     | Brown     | 10000.00| 10000.00              | 0.00              |


Explanation:
For each employee, "avg_department_salary" represents the average salary of employees in the same department.
"salary_difference" represents the difference between the employee's salary and the average departmental salary.
