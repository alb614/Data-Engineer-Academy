Introduction to Subqueries in Conditional Logic:
Subqueries within conditional logic enable dynamic decision-making based on data relationships and values.

Subqueries are used within WHERE, FROM, and HAVING clauses for tailored data retrieval.

 

Common Use Cases:
a. Filtered Selection: Retrieving rows based on related conditions.

b. Subquery Comparisons: Comparing values with results from another query.

c. Subqueries in CASE Statements: Using subqueries to generate conditional results.

 

Practical Examples:
 

Example 1 - Subquery in WHERE Clause:

SELECT product_name, unit_price FROM products WHERE unit_price > (SELECT AVG(unit_price) FROM products);

Example 2 - Subquery with IN Operator:

SELECT customer_name FROM customers WHERE customer_id IN (SELECT customer_id FROM orders WHERE order_status = 'Shipped');

Example 3 - Subquery in CASE Statement:

SELECT product_name, CASE WHEN unit_price > (SELECT AVG(unit_price) FROM products) THEN 'Above Avg' ELSE 'Below Avg' END AS price_category FROM products;
 

 

Subqueries with Aggregate Functions:

Question:
Retrieve product_id, product_name, unit_price and category that have a price higher than the average price of products within their respective categories.

Table: products 

ColumnName          DataType
product_id          int
product_name        varchar 
category            varchar
unit_price          decimal


Constraints:
The input table products contains valid data.


Sample Input:
products                                     
| product_id | product_name   | category  | unit_price |
|------------|-----------------|-----------|------------|
| 1          | Laptop          | Electronics | 1000.00    |
| 2          | Smartphone      | Electronics | 500.00     |
| 3          | Coffee Maker    | Appliances  | 50.00      |
| 4          | Blender          | Appliances | 30.00      |
| 5          | Headphones       | Electronics | 80.00      |


Sample Output:
| product_id | product_name   | unit_price | category    |
|------------|-----------------|------------|-------------|
| 1          | Laptop          | 1000.00    | Electronics |
| 3          | Coffee Maker    | 50.00      | Appliances  |


Explanation:
For the Electronics category, the average price is (1000 + 500 + 80) / 3 = 526.67. So, Laptop is selected as its prices is higher.
For the Appliances category, the average price is (50 + 30) / 2 = 40. So, Coffee Maker is selected as its price is higher.
