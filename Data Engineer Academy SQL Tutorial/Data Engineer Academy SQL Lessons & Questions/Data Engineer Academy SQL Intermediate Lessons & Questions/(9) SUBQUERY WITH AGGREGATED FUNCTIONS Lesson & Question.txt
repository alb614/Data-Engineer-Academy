This document provides a comprehensive understanding of using subqueries to aggregate data in multiple stages, along with syntax, use cases, and practical examples, empowering your data manipulation skills on your edtech platform.

 

Introduction to Aggregating Data in Stages:
Aggregating data in multiple stages involves breaking down complex calculations into sequential steps.

Subqueries help achieve stage-by-stage data manipulation for more refined analysis.

 

Common Use Cases:
a. Cumulative Summation: Calculating running totals for various groups.

b. Incremental Averages: Finding the average as new data points are added.

c. Comparative Analysis: Comparing aggregates between different groups.

Stages of Aggregation: a. Stage 1: Extract relevant data for each group. b. Stage 2: Perform aggregate functions on extracted data. c. Stage 3: Combine results or perform further calculations.

 

Practical Examples:
 

Example 1 - Sales Aggregated by Month:
SELECT month, SUM(amount) AS monthly_sales FROM (SELECT DATE_FORMAT(order_date, '%Y-%m') AS month, order_amount AS amount FROM orders ) AS stage1 GROUP BY month;

Example 2 - Running Average of Daily Average Ratings:
SELECT rating_date, AVG(rating) OVER (ORDER BY rating_date) AS avg_rating FROM (SELECT rating_date, AVG(rating) AS rating FROM ratings GROUP BY rating_date ) AS stage1;

Example 3 - Year-over-Year Revenue Growth by Region:
SELECT region, revenue_2022, revenue_2023, (revenue_2023 - revenue_2022) / NULLIF(revenue_2022,0) AS growth_rate FROM 
(SELECT region, SUM(CASE WHEN year = 2022 THEN revenue ELSE 0 END) AS revenue_2022, SUM(CASE WHEN year = 2023 THEN revenue ELSE 0 END) AS revenue_2023 FROM sales GROUP BY region) t;
